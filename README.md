# JBlockStorage

Курсовой проект Нурмагомедова Р.Р., НИУ ВШЭ, 2026.

Децентрализованная система хранения файлов — файлы шифруются, режутся на шарды и раскидываются по нескольким узлам в P2P-сети. Метаданные хранятся в блокчейне. Никакого центрального сервера нет.

---

## Что умеет

**Хранение файлов**
- Загрузить файл: он автоматически шифруется (AES-256-GCM), режется на шарды и раскидывается по узлам сети с заданным коэффициентом репликации (по умолчанию 3). Узел, который загружает файл, сам становится одним из хранителей — то есть для `replication=3` достаточно 3 узлов в сети, а не 4.
- Скачать файл с любого узла, у которого есть доступ. Если один из хранителей упал — система автоматически добирает недостающие шарды с оставшихся.
- Удалить файл: запись в блокчейне помечается удалённой, шарды больше не раздаются.

**Безопасность**
- Всё зашифровано: AES-256-GCM для данных, RSA-OAEP для ключей.
- Каждый пользователь — это пара RSA-ключей. Никакого центрального сервера авторизации нет.
- При создании профиля генерируется BIP-39 мнемоническая фраза (12 слов). По ней можно восстановить доступ на любом устройстве.

**Расшаривание**
- Поделиться файлом с другим пользователем: AES-ключ файла перешифровывается под публичный ключ получателя — раздавать сам файл не нужно.
- Получатель видит расшаренные ему файлы в отдельном разделе.

**Сеть**
- P2P без центрального сервера: узлы находят друг друга через seed-адреса и обмениваются списком пиров (gossip).
- Работает полностью в LAN или VPN — интернет не нужен.
- После долгого offline узел автоматически синхронизирует блокчейн при переподключении.
- Если хранитель вышел из сети — система инициирует перерепликацию на другие узлы.

**Интерфейс**
- Полноценный JavaFX GUI: мои файлы, расшаренные мне, контакты, настройки.
- Прогресс загрузки в реальном времени: шифрование → шардирование → передача → подтверждение.
- Свойства файла: метаданные, шифрование, список хранителей со статусом online/offline.

## Стек

- Java 17, JavaFX (GUI)
- Netty (P2P-сеть)
- RocksDB (локальное хранение блокчейна и шардов)
- Bouncy Castle (крипто: AES-GCM, RSA-OAEP, BIP-39)
- Gradle (сборка)

---

## Быстрый старт

**Требования:** JDK 17+, Gradle 8+

```bash
# Сборка
./gradlew clean build

# Запуск GUI
./gradlew run

# Три узла локально (Alice / Bob / Carol на портах 8081/8082/8083)
./scripts/run-3-nodes.sh
```

Данные каждого узла хранятся в `~/.jblockstorage-<username>` (имя пользователя системы).  
Чтобы сбросить состояние сети, не теряя ключи:

```bash
rm -rf ~/.jblockstorage-*/data
```

| `JBS_HOME`   | `~/.jblockstorage`   | Папка данных узла               |
| `JBS_PORT`   | `8081`               | Порт P2P                        |
| `JBS_SEEDS`  | —                    | `host:port` seed-узлов через `,`|
