# Демо-сценарий: 3 узла на одном Mac

Для проверки flow с расшариванием/скачиванием и для демонстрации
приёмки по ТЗ (п. 8.2.1) нужно запустить минимум 3 узла одновременно.
GUI поддерживает это через переменные окружения.

## Переменные окружения

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `JBS_HOME` | База приложения: `<JBS_HOME>/profiles/`, `<JBS_HOME>/data/<profile>/...`. Каждый узел должен иметь свою. | `~/.jblockstorage` |
| `JBS_PORT` | TCP-порт для входящих соединений. | `8080` |
| `JBS_SEEDS` | Список seed-узлов в формате `host:port,host:port`. | (пусто) |

Без этих переменных GUI работает как раньше: один узел на 8080,
данные в `~/.jblockstorage/`.

## Быстрый старт через скрипт

```bash
chmod +x scripts/run-3-nodes.sh
./scripts/run-3-nodes.sh
```

Скрипт откроет три окна Terminal.app и запустит в каждом по узлу.
По умолчанию используется Terminal.app; если хочешь iTerm2 —
`TERMINAL_APP=iTerm ./scripts/run-3-nodes.sh`.

## Первый запуск: создаём 3 профиля

Скрипт поднимает узлы на портах 8081/8082/8083. Каждый запустится с
пустой `JBS_HOME`, поэтому при первом запуске GUI откроется на экране
Welcome → «Создать профиль».

В каждом окне создай свой профиль:

| Окно | Профиль | Порт | Seeds |
|---|---|---|---|
| A | Alice | 8081 | — |
| B | Bob | 8082 | 127.0.0.1:8081 |
| C | Carol | 8083 | 127.0.0.1:8081, 127.0.0.1:8082 |

Пароли можно поставить простые — это локальное демо.

После создания каждый профиль автоматически логинится. В sidebar
появится «Сеть стабильна · 2 подключения» (или 1 — пока другие узлы ещё
не подключились).

## Что проверять

### 1. Загрузка файла (Upload)

В окне Alice → «Мои файлы» → «Загрузить файл». Если кнопка серая,
значит активных пиров < 3 — подожди пока Bob и Carol подключатся (видно
в sidebar «12 подключений» — должно быть минимум 2).

После загрузки файл появится в таблице.

### 2. Расшаривание (Share)

Сначала забери публичный ключ Bob: в окне Bob → «Настройки» (или прямо
из его keystore-файла `~/.jblockstorage-B/profiles/Bob.pub`).

В окне Alice → правый клик на загруженный файл → «Расшарить» → вставь
публичный ключ Bob → «Поделиться».

В окне Bob → «Расшаренные мне» → файл от Alice должен появиться
(возможно, нужно переключить раздел туда-обратно — список обновляется
при показе).

### 3. Скачивание (Download)

В окне Bob → «Расшаренные мне» → «Скачать» → выбери куда сохранить.
Если хеши совпадут с оригиналом (можно проверить `shasum`) — критерий
ТЗ п. 8.2.1.6 «целостность» выполнен.

### 4. Имитация сбоя (ТЗ п. 8.2.1.4)

Закрой окно Bob (или нажми Ctrl+C в его терминале). Из Carol попробуй
скачать тот же файл, что был у Alice — он должен скачаться, потому что
у Alice и Carol по копии шардов (replication factor = 3).

## Сброс данных

```bash
rm -rf ~/.jblockstorage-A ~/.jblockstorage-B ~/.jblockstorage-C
```

После этого `./scripts/run-3-nodes.sh` опять покажет Welcome во всех
окнах, и можно начать с чистого листа.

## Запуск одного узла вручную

Если скрипт не подходит (например, тестируешь в одном терминале),
можно вручную:

```bash
# Терминал 1:
JBS_HOME=$HOME/.jblockstorage-A JBS_PORT=8081 ./gradlew run

# Терминал 2:
JBS_HOME=$HOME/.jblockstorage-B JBS_PORT=8082 \
  JBS_SEEDS=127.0.0.1:8081 ./gradlew run

# Терминал 3:
JBS_HOME=$HOME/.jblockstorage-C JBS_PORT=8083 \
  JBS_SEEDS=127.0.0.1:8081,127.0.0.1:8082 ./gradlew run
```

## Известные ограничения

- **RocksDB lock.** Один и тот же `JBS_HOME` нельзя открыть из двух
  процессов одновременно. Если перепутал переменные и второй узел не
  стартует с ошибкой про блокировку — закрой первый, поправь и запусти
  снова.
- **Порты.** Если 8081/8082/8083 заняты — поправь в скрипте.
- **Bind на 0.0.0.0.** Узлы слушают на всех интерфейсах. Для демо на
  одном компе это не имеет значения, но если планируешь запускать узлы
  на разных машинах — убедись, что фаервол пропускает.
